# Proposed Hardware Baseline

- Raspberry Pi 5 (8 GB proposed), robust power supply and cooling/enclosure
- SSD-based persistent storage (avoid relying solely on microSD for logs)
- Isolated RS-232 interface compatible with the verified radio modem electrical and serial parameters
- UPS and safe shutdown, surge protection, time synchronization / RTC as needed
- Ethernet firewall/router; local monitor or touchscreen optional

Future candidates: industrial Raspberry Pi or fanless industrial PC if environmental or reliability assessment requires them. Actual power, grounding, lightning exposure, temperature, and radio/modem interfaces must be surveyed before installation.

# Shared Historical-to-Modern Interface Definitions

Store **verified** RTU addressing, packet framing, units, sensor mappings, and command meanings used by both versions. Shared definitions should cite their historical source and indicate validation status. Avoid silently modifying historical evidence.

Existing working documents remain at [protocol data dictionary](../Docs/Protocol_Data_Dictionary.md) and [communications documentation](../Docs/Communications.md) pending reconciliation.
